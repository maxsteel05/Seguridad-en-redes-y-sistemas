# Reto

## Descripción

What is 0x3D (base 16) in decimal (base 10)?

## Solución

### Solución 1

- Usando Python.

```bash
maxsteel05-picoctf@webshell:~$ python
>>> int(0x3d)
61
```

## Flag

`picoCTF{61}`

## Notas

- `0x` indica que el número está escrito en hexadecimal.
- `0x3D` en hexadecimal equivale a `61` en decimal.
- `int()` permite obtener el valor entero del número.
